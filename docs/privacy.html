Privacy Policy: Hypothetica Studio

Last updated: 25 November 2026

Hypothetica Studio is an internal tool used only by the owner of the Hypothetica YouTube channel. It is not available to the public.

What data it accesses

  • Permission to upload videos, thumbnails, captions and playlists to the owner's own YouTube channel.
  • Read-only access to that channel's YouTube Analytics (views, watch time, impressions and similar aggregate metrics).

How the data is used and stored

Analytics are used only to decide which videos to make next. Aggregate metrics may be stored in the channel's own private project files. The OAuth credentials are stored in encrypted repository secrets and are never shared.

Sharing

No data is sold, shared with third parties, or used for advertising. The tool does not access any other user's data.

Google API Services

Hypothetica Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/novatic11/whatif-studio/issues.
